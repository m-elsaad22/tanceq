# ركن التطور — إدارة المواقع حسب الدولة

لوحة مركزية لإدارة كل تثبيتات ووردبريس الخاصة بـ **ركن التطور** (تثبيت مستقل لكل دولة)، مع التنقل السريع بين لوحات التحكم.

## ماذا تفعل؟

- إضافة كل دولة برابط تثبيت ووردبريس الخاص بها
- فتح لوحة تحكم ووردبريس لأي دولة بضغطة واحدة
- التبديل السريع بين الدول من أعلى الصفحة
- اختصارات لأقسام الإدارة (مقالات، صفحات، إضافات، تحديثات…)
- فحص حالة كل موقع

## التشغيل

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

## ملاحظات

- البيانات تُحفظ محلياً في `data/sites.json`
- حذف دولة من اللوحة لا يحذف موقع ووردبريس نفسه
- استبدل الروابط التجريبية بروابط التثبيتات الحقيقية لكل دولة
