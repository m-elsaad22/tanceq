# NATIONAL CONTRACTING — Solar Technical & Commercial Proposal

Interactive A4 HTML quotation for **Temporary Site Offices – Solar Power Supply** at Rawdat Al Sidr, Sharjah, UAE.

## Open (mobile-safe)

**Use the single-file document** (CSS, JS, and images are embedded):

- `Solar-Quotation.html` or `index.html`
- Download ZIP: `NATIONAL-CONTRACTING-Solar-Quotation.zip`

On Android: extract the ZIP fully, then open `Solar-Quotation.html` in Chrome. Do not rely on opening HTML from inside an archive viewer (`content://`), which often blocks styles.

```bash
python3 -m http.server 8765
# http://127.0.0.1:8765/Solar-Quotation.html
```

## Files

| Path | Role |
|------|------|
| `Solar-Quotation.html` / `index.html` | Self-contained 18-section proposal |
| `styles.css` / `script.js` / `assets/` | Source modules (for editing/rebuild) |
| `NATIONAL-CONTRACTING-Solar-Quotation.zip` | Direct download package |

## Features

- **OPTION 01** Off-grid PV + LiFePO₄ ESS (no diesel / no grid)
- **OPTION 02** Hybrid PV + ESS + new diesel genset + ATS
- Editable BOQ with live Subtotal / Discount / VAT 5% / Grand Total (AED)
- Edit Mode, Hide Prices, show Option 01 / 02, Print / Save as PDF
- English ↔ Arabic (RTL)
- Client load schedule preserved (161 kW) with technical notes on 201.25 / 221 / ~200 kVA variance
- Sizing fields left as TBD — no invented yields or savings guarantees
- Product cards clearly marked **Illustrative** / reference class

## Notes

- Do not treat blank unit prices as a free offer; enter supplier rates in Edit Mode.
- Proposer company name, phone, email, and stamp fields are editable placeholders — not invented.
- Final system sizing remains subject to detailed load analysis and confirmation of actual operating demand.
